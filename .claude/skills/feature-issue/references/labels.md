# 라벨 세트 (한글)

이 스킬은 아래 라벨 안에서만 고른다. 목록에 없는 라벨을 새로 만들지 않는다.
`scripts/create_feature_issue.py`의 `LABELS` 사전과 동기화해서 관리한다.

## 유형 (정확히 1개)

| 라벨 | 색상 | 설명 | 언제 쓰나 |
|---|---|---|---|
| 기능 | `#0E8A16` | 새 기능 추가 | 새 분석, 새 스크립트, 새 산출물 |
| 개선 | `#A2EEEF` | 기존 기능 개선 | 성능, 정확도, 기존 분석 확장 |
| 버그 | `#D73A4A` | 오류 수정 | 잘못된 계산, 깨진 결과 |
| 문서 | `#0075CA` | 문서 작업 | README, 설명 문서 |

## 주제 (0~1개)

현재 저장소의 분석 주제에 대응한다.

| 라벨 | 색상 | 설명 | 대응 파일 |
|---|---|---|---|
| 혼잡도 | `#FBCA04` | 혼잡도 분석 | `analyze_congestion.py`, `results/congestion_*` |
| OD | `#F9D0C4` | 정류장 OD 분석 | `analyze_od.py`, `results/od_*` |
| 환승 | `#C5DEF5` | 환승 분석 | `analyze_transfer.py`, `results/transfer_*` |
| 운임 | `#BFD4F2` | 운임 분석 | `analyze_fare.py`, `results/fare_*` |
| 데이터 | `#D4C5F9` | 데이터 준비·갱신 | `make_dummy_data.py`, `data/` |

## 판단 기준

- 유형은 "이 변경이 무엇을 위한 것인가"로 고른다. 새 분석 추가는 `기능`, 기존 분석 정확도 개선은 `개선`.
- 주제는 파일 경로로 판단한다. 여러 주제에 걸치면 가장 중심이 되는 하나만 고르고, 판단이 애매하면 주제 없이 둔다.
- 라벨이 세트에 없는 주제(예: 새 분석 주제)가 필요하면 스킬이 만들지 말고 사용자에게 먼저 묻는다.
